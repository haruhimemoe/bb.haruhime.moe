A small API for scripts and bots. Every call needs a key from your account page.

## Authentication

Make a key on your [account page](/account). It starts with `hbb_` and is shown once. Send it on every call:

```
Authorization: Bearer hbb_…
```

A missing, revoked or replaced key gets a 401. Regenerating a key stops the old one at once.

## Limits

- Requests: 60 a minute, counted per key owner.
- Writes (POST, PUT, PATCH, DELETE): 10 a minute, counted per key owner.
- Failed calls (missing or bad key): 20 a minute, counted per IP.

Every answer carries `RateLimit-Limit`, `RateLimit-Remaining` and `RateLimit-Reset`. Over the limit you get a 429 with `Retry-After`.

## GET /api/v1/me

Who the key belongs to.

```sh
curl -H "Authorization: Bearer hbb_…" https://bb.haruhime.moe/api/v1/me
```

```json
{ "user": { "id": "…", "osuId": 2, "username": "peppy" } }
```
